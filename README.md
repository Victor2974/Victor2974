## Sobre mim

Sou estudante de **Análise e Desenvolvimento de Sistemas** na USCS (conclusão prevista em dez/2027) e trabalho com foco em **back-end**: APIs REST em Java e Spring Boot, persistência com JPA e bancos relacionais. Gosto de software que resolve problema de verdade, e já levei isso para fora da faculdade:

- **Automação na YKZ Confecções:** criei uma automação em Google Apps Script que eliminou o lançamento manual de pedidos do setor de corte.
- **Desenvolvimento web para clientes:** projeto e publico sites para pequenos negócios com Astro, React, TypeScript e Tailwind, com deploy na Vercel.
- **Agora:** construindo uma API de gestão de pedidos inspirada nesse fluxo real de produção (Spring Boot + PostgreSQL).
